# 织见：经营数据分析

个人实践项目。

## 功能流程

从中文业务问题出发，定位表字段与指标口径，生成只读 SQL，查询后返回结果与解释。复杂问题可拆成多个子查询，再汇总报告。

## 页面怎么看

问数：查看营业收入和统计期间。

分析：比较两个期间的收入、成本与费用。

历史：重新打开已保存分析。

## 技术与展示边界

Python、MySQL、LangGraph、模型 API。截图回放使用项目保存的模拟运行记录，不代表在线提供查询服务。
